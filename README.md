# 🚀 FinSight Pro — Financial Forecasting Platform

## 📊 Overview

FinSight Pro is a **Django-based financial analysis tool** that helps users perform advanced calculations like break-even analysis, NPV, IRR, forecasting, and Monte Carlo simulations.

---

## ✨ Key Features

* 📌 Break-Even Analysis (Bisection & Newton-Raphson)
* 📈 Revenue Forecasting (Regression Models)
* 💰 NPV & IRR Calculation
* 🎲 Monte Carlo Simulation
* 🔐 User Authentication System
* 🕘 Analysis History Tracking
* 🌙 Modern Dark-Themed UI

## ⚙️ Installation

```bash
git clone https://github.com/aayushkhanna198-cmd/finsight-pro.git
cd finsight-pro
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Open: http://127.0.0.1:8000/
